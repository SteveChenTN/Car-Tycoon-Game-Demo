## 📋 测试脚本列表

### `test_production_flow.py` - 生产流程完整测试

**测试内容：**
1. ✅ 创建V8引擎设计（5.0L V8, 自然吸气）
2. ✅ 创建引擎工厂（6级工厂，90%效率）
3. ✅ 初始化材料市场（5种材料）
4. ✅ 采购100吨钢材及其他必要材料
5. ✅ 生产50台V8引擎
6. ✅ 验证引擎库存正确增加（+50台）
7. ✅ 验证钢材库存正确减少
8. ✅ 验证其他材料消耗正确
9. ✅ 验证质量守恒（材料总量平衡）

**运行方法：**
```bash

python backend/scripts/init_world.py
python backend/scripts/migrate_production.py

# 运行测试
python backend/test_scripts/test_production_flow.py
```

## 🚀 如何添加新测试

1. 创建新的测试脚本文件：`test_xxx.py`
2. 继承或参考现有测试结构
3. 包含完整的：
   - 环境准备
   - 测试执行
   - 结果验证
   - 清理（如需要）
4. 更新本README

4. 日志输出详细，便于调试
